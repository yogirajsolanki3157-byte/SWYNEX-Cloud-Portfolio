SWYNEX – Cloud Portfolio Website

📌 Project Overview

This project is developed as part of Task 2 of the SWYNEX Technologies Cloud Computing Internship.

The SWYNEX Cloud Portfolio is a responsive website designed to showcase cloud computing knowledge, technical skills, and projects.

🎯 Project Objectives

- Develop a responsive portfolio website.
- Understand frontend web development.
- Learn GitHub project management.
- Deploy a static website using a cloud hosting platform.
- Understand basic hosting, monitoring, and security concepts.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
- Netlify (Planned Hosting Platform)
